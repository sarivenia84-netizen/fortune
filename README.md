# Fortune Cookie for an AI Agent

This program writes one fortune-cookie line for an AI agent to `entry.txt`. It was built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty.

Run it with Python 3.13:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```

When `MAKEFUN_OUTPUT_DIR` is unset, the program writes `entry.txt` in the current directory.
